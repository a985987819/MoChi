## 文件级实现细节

### 服务层

- `src/services/pet-state.ts`：`PetStateManager`——三槽位（system/presence/mood）+ `recompute()` 仲裁（优先级见 08 §2.2）；每槽独立过期定时器，mood 默认 6~10s 随机寿命；`state://pet-changed` 广播 + 本窗订阅者回调；`installRemoteListeners()` 接收 `state://set-mood|set-system|clear-system` 跨窗口遥控（载荷校验失败静默忽略）。**只管仲裁不管图片**。
- `src/services/pet-assets.ts`：`listVariants(state)`——用户目录（Rust 命令扫描 + `convertFileSrc` 转 asset URL）→ 内置（`import.meta.glob` 构建期映射）→ 空数组（渲染层显示占位 SVG）；`parseAssetName` 与 Rust 侧 `pet_state_of_file_name` 是同一约定的两份实现（名字正则 + jpeg 归一 + 纯数字后缀剥离）。

### Rust 层

- `list_user_pet_assets` 命令：扫 `{appData}/pet-assets/` 返回 `{状态: [完整路径]}`；不存在的目录返回空 map（回退链走内置）。**不引入 tauri-plugin-fs**——前端不持通用文件权限，只开这一个窄命令（应用命令默认允许调用，插件命令才需逐条 ACL）。
- `ui://quit-app` 事件监听（右键菜单退出入口）。

### 配置

- `tauri.conf.json`：`security.assetProtocol = { enable: true, scope: ["$APPDATA/pet-assets/**"] }`——asset 协议只对用户素材目录放行；CSP `img-src` 增加 `asset: http://asset.localhost`。
- `Cargo.toml`：tauri features + `protocol-asset`（与 conf 联动，机制同 macos-private-api）。
- `tsconfig.json`：lib 升 ES2021（`replaceAll` 需要）。

### UI 层

- `PetApp.tsx`：`usePetState`（订阅仲裁）+ `usePetAsset`（解析/随机取图/静态变体轮换自递归定时器，状态切换即重置）；渲染 `<img>` 或占位 SVG。
- `ContextMenu.tsx`：自绘菜单，位置夹紧到 220×260 视口；表情演示按钮——情绪类走 mood 槽、功能类走 system 槽 8s（正好演示"系统状态抢占情绪、超时后情绪恢复"）。
- 10 个 SVG：`src/assets/pet/{state}.svg`，共享团子轮廓，各状态独立表情/道具（happy 笑眼、sad 泪滴、thinking 思考泡、alert 感叹号气泡、focus 头带、break 咖啡、sleep Zzz…）。

### 依赖变化

- npm：无新增；cargo：无新增（仅 feature 开关）。

## 设计取舍

1. **每次解析重扫目录，而非 watcher**：目录 ~10 文件 readdir 毫秒级，换取"放图即生效/删图即回落"，省掉 notify watcher + 事件桥的复杂度（见 pet-assets.ts 头注释）。
2. **自定义窄命令而非 tauri-plugin-fs**：插件会把宽泛的 fs 权限面暴露给前端；一个只读扫描命令是最小权限解。
3. **SVG 而非脚本生成 PNG**（roadmap 原步骤写"脚本生成 PNG"）：SVG 文本可读、体积小、逐状态手绘表情质量高于程序化生成，且零构建工具依赖——与占位兜底（MochiPlaceholder）形成"风格连续"的回退链。
4. **仲裁与渲染分离**：PetStateManager 不知道图片存在；PetApp 不知道优先级规则存在——两侧可独立测试与替换。
5. **交互契约先行**：`ui://reset-standup` 在无监听者时静默丢弃，v0.7.0 只加 Rust 监听不改前端——事件协议的"前向兼容"红利。

## 踩坑与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| TS2344 `keyof this` 不满足约束 | 类体内对私有字段取 keyof 解析异常 | 引入 `type SlotName = "system"\|"presence"\|"mood"` 别名 |
| TS2550 replaceAll 不存在 | lib ES2020 无该方法类型 | tsconfig lib 升 ES2021（运行时 WebView2/WKWebView 均支持） |
| tauri 报 features 与 conf 不匹配 | assetProtocol 配置需要 `protocol-asset` feature | Cargo.toml 补 feature（与 macos-private-api 同款联动机制） |
| E0382 use of moved value `handle` | quit 监听复用了已被前一个 move 闭包夺走的 AppHandle | 再 clone 一份——AppHandle 廉价克隆是惯例，忘了就是 E0382 |
