# v0.24.0 — 素材管理增强：多图轮换 + 缩略图删除 + 命名复制

> 用户诉求：① 同一状态多张图 + 自动命名 + 每 5 分钟随机一张；② 缩略图与删除；
> ③ 每状态上传默认递增命名。2026-11-18。

## 现状与差距

- 多图与自动命名**已支持**（变体池 + `targetFileName` 递增命名，v0.10.0/v0.23.0）；
- 轮换已存在但节奏是 **5~9 秒**——用户明确要 **5 分钟**；
- 缩略图与删除**缺失**——用户看不到自己传了什么、删不掉。

## 功能清单

1. **轮换节奏 5~9 秒 → 5 分钟**（+0~20s 抖动）：静态多图是"换表情"不是"放幻灯片"；
   动画图（gif/webp）与帧序列照旧不参与轮换。docs/pet-assets.md 同步（3 处）。
2. **缩略图 + 两步删除**：状态卡片显示该状态全部用户图的缩略图（52px，asset 协议），
   右上 × → 变「确认删除」→ 再点真删（两步防误删）。新 Rust 命令
   `delete_user_pet_asset`：canonicalize 后校验路径必须落在 pet-assets 目录内
   （防任意删除，与 v0.17 备份导入同一守卫模式）。
3. **每状态上传默认递增命名**（v0.23.0 已实现，本轮在多图提示中显式说明）：
   选 N 张 → 自动命名 `{状态}.png` / `{状态}_2.png` / `{状态}_001.png`（帧），
   确认列表展示前后对照。
4. 多图说明补进素材页（双语 lead）：同一状态可放多张 + 每 5 分钟随机换一张。

## 设计取舍

1. **删除走 Rust 而非前端 fs**：前端无文件系统权限（AGENTS.md），删除与导入/列目录
   同样收在 Rust 命令里，路径守卫（canonicalize + starts_with）防 IPC 任意删除。
2. **两步确认而非弹窗**：× → 「确认删除」就地翻转，误点成本一次额外点击，无模态
   打断（与备份导入的两步确认同一交互语言）。
3. **删除后即时重扫**：素材页 refresh + 宠物窗下次解析自动反映（每次解析都重扫
   用户目录的既定设计）——删图即回落，与放图即生效对称。
4. **5 分钟是字面值 + 20s 抖动**：用户明确"每 5 分钟"；抖动避免多个状态切换计时器
   同拍换图的机械感，幅度小到感知不到偏差。
