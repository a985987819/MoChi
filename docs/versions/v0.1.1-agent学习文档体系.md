## 关键规范决策（文档先行，代码须遵守）

1. **事件协议**：Provider 产出 `StreamEvent`（text-delta / tool-calls / finish / error），循环产出 `AgentEvent`（text-delta / step-end / done）；tool-calls 组装后一次发出；
2. **工具结果统一 JSON 字符串**、错误回传不抛出（自愈机制）、`MAX_STEPS=8`；
3. **上下文五层预算**（system 800 / memories 400 / history 4000 / RAG 按需 / 输入必留），裁剪按"块"保证 tool 配对完整性；
4. **mood 机制选型**：专用工具 `set_pet_state`（否决 JSON mode 与文本标记，理由见 03 §4.3）；
5. **表结构**：sessions / messages（存协议原样）/ todos / memories 四表 DDL 定稿（04 §3.1）；
6. **RAG**：BM25(k1=1.5,b=0.75) + 中文 bigram + 同义词查询扩展 + Hit@3 评测门槛 9/10；`Retriever` 接口与记忆检索共用。
