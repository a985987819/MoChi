# v0.13.1 — 字体可读性：去掉楷体、消除半像素

## 目标

用户反馈："字体有点模糊看不清，希望让笔画更加凌厉一些，或者不采用这种楷体。"

排查后确认**只有宠物头顶气泡用了楷体**（`"STKaiti", "KaiTi"`），其余界面一直是系统无衬线。
但"糊"还有第二个来源：全站 36 处**小数像素字号**（12.5 / 13.5 / 11.5 / 10.5），
字形落在半像素上，抗锯齿后边缘发灰。本版两件一起修。

## 功能清单

- [x] 气泡字体：楷体 → 系统无衬线（`Segoe UI Variable Text` → `Segoe UI` → `Microsoft YaHei UI`
      → `Microsoft YaHei` → `PingFang SC`）。
- [x] 气泡排版：12px/17px/500 + `letter-spacing: 0.15px` → **13px/19px/400 + 正常字距**。
- [x] 全站字体栈统一：聊天窗 / 提醒窗 / 右键菜单都补上 `Segoe UI Variable Text`（Win11 可变字重）
      与 `Microsoft YaHei UI`（中文 UI 优化版），中文排在 `sans-serif` 之前。
- [x] 小数像素字号归一（5 个 CSS 文件共 36 处）：`.5` 一律进位到整数。
- [x] 版本对齐 0.13.1，安装包 `run_here/windows/Mochi_0.13.1_x64-setup.exe`。

## 设计取舍

**① 为什么是系统无衬线，而不是更"凌厉"的粗体**
用户说的"凌厉"是**笔画边缘实**，不是"更粗"。把 12px 的楷体改成 500 粗的无衬线会得到
"糊且胖"；正确做法是换字族 + 去掉小数像素，让抗锯齿落在整像素上。字重保持 400，
需要强调的地方项目里本来就用 600（标题、按钮）。

**② 为什么不自带字体（思源黑体 / HarmonyOS Sans 等）**
自带字体要打进安装包（中文全字重动辄 5~10MB），还要处理授权与加载时机（首屏 FOUT）。
系统字体在 Windows 上是雅黑 UI / Segoe UI，本来就是系统 UI 的"原生气质"，
桌宠是贴在桌面上的小东西，跟着系统走反而不突兀。**这一条可以推翻**：如果哪天想要
"品牌字形"，再引入一个子集化字体（只保留常用 3500 字，约 1.5MB）。

**③ 为什么整数像素这么重要**
12.5px 的中文在 100% 缩放下，横画常常落在 0.5px 边界上，抗锯齿会把它摊成两条半透明的灰线，
观感就是"发虚"。改整数后横画占满一个整像素，边缘立刻变实。同理去掉了 `0.15px` 的字距
（每个字右移 0.15px，累积起来整行都发毛）。

**④ 字号整体 +1px 的影响**
12.5→13 / 13.5→14 / 11.5→12 / 10.5→11。已验证聊天窗 5 个 Tab 仍能在一行放下（截图确认），
其余为提示类文本，高度有弹性。

## 踩坑与解决

### ① 只有气泡是楷体，"全站换字体"是误判

第一反应是"全站字体有问题"，但 grep 发现只有 `.pet-bubble` 用了 `STKaiti/KaiTi`。
所以先把**真正的病灶**改掉，再做"顺手能提升清晰度"的两件事（统一字体栈、整数字号），
而不是无差别换字体——后者会白白改变已经稳定的界面观感。

### ② 批量改字号要能复核

用脚本把 `font-size: N.5px` 统一进位，改完 `grep` 确认没有残留小数，
再用 CDP 截图看 Tab 栏有没有被挤换行。纯文本替换最怕"改了 36 处、其中一处改错"，
所以验证要落在**画面**上而不是只数改动。

### ③ 截图验证顺手发现聊天记录里有余留的测试消息

截图时看到历史里有"恢复后合并提醒：回个电话…""到点提醒：每日喝水"等行——那是前面
端到端验证写进 `messages` 表的测试数据（当时只删了 `reminders` / `todos`）。
已一并清理（保留了用户自己的那条 Mock 回复）。**教训**：验证脚本凡是会写库的，
清理范围要覆盖它写过的每一张表。

## 说明

"清晰、凌厉"是主观感受。如果你觉得 13px 还偏小，或者希望正文再粗一档，
可以只改 `pet.css` 里 `.pet-bubble` 的 `font-size` / `font-weight` 两个值；
聊天窗的字号集中在 `chat.css`，改基数字号即可整体放大。
