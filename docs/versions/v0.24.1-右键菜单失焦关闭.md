# v0.24.1 — 右键菜单失焦关闭（补丁）

> 用户诉求："右键唤起的按钮应该在失焦之后就关闭"。2026-11-18。

## 根因

ContextMenu 的关闭监听是 **document 级 mousedown + Escape**——都只能收到本窗口
（宠物 WebView）内的事件。用户右键唤起菜单后点开聊天窗（或任何其他应用），
那次点击发生在别的窗口里，宠物窗的 document 永远收不到——菜单悬在失去焦点的
窗口上不走。

## 修复

`ContextMenu.tsx` 关闭监听补 **window blur**：本 WebView 失去 OS 焦点的瞬间
（点击其他窗口 / Alt-Tab / 最小化）触发 `onClose()`。与本窗口内的 mousedown
（点菜单外）和 Escape 三条关闭路径并存。

## 设计取舍

1. **用 DOM blur 而非 Tauri focus 事件**：`window blur` 是标准事件且覆盖同一语义
   （本 WebView 失去前台焦点），无需额外监听 `tauri://blur` 桥接。
2. **失焦即关，不区分原因**：Alt-Tab、点别的应用、最小化都算"用户去了别处"——
   菜单是临时性浮层，任何焦点离开都该收起（与系统右键菜单行为一致）。
