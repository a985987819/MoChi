# v0.26.0 — 主题色：调色盘无级选色，全站粉色系跟随

> 用户诉求："增加主题色功能，目前粉色作为默认，可唤起调色盘无级调节，设置等相关
> 页面的粉色自动随之改变"。2026-11-19。

## 功能清单

1. 设置页新增「主题色」分区：**原生调色盘**（`input[type=color]`，无级选色）+
   4 枚预设色板（蜜橙/天空/抹茶/薰衣草）+ **恢复默认粉**按钮。
2. 拖动调色盘**即时预览**（本窗令牌内联覆盖），持久化防抖 350ms → settingsChanged
   广播 → 其余窗口跟随（聊天/宠物菜单/气泡/提醒弹窗全部生效）。
3. 派生范围 = accent 家族 7 枚令牌（fill/text/muted/soft/tint/border/ring）；
   中性底色（奶油纸面/卡片/文字灰阶）不跟随——换糖霜不换纸。
4. 默认粉 `#ff8fab` **不走派生**：theme.css 手调值直接生效（恢复默认即移除内联覆盖）。
5. 深浅主题各派生一套：文字档用亮度搜索保证 WCAG ≥4.5（浅色向暗搜、深色向亮搜），
   fill 向暗搜索保证白字 ≥2 可见。

## 设计取舍

1. **默认色不派生**：theme.css 的粉是手调的（text 档 #b3455a 的饱和度并非从
   #ff8fab 机械推导），派生函数对任意色给出"达标"结果，但手调默认更精致——
   恢复默认 = 移除内联覆盖，让 stylesheet 接管。
2. **对比度用搜索而非公式**：同色相下明度与对比度单调（明度越低对白底对比越高），
   逐 1% 步进到首个达标值即可；端点兜底保证函数总能返回。
3. **中性底色不跟随**：换糖霜不换纸——粉改蓝时奶油纸面照旧（用户诉求只提"粉色
   随之改变"）；中性灰阶若跟随会产生"主题色污染"。
4. **极端选色的钳制**：近白 fill 压暗到对白字 ≥2、明度钳 40~78；文字档搜索起点
   钳在可达区间——用户选黄色/灰色也能得到可读的界面（31 例单测含全部极端场景）。
