# v0.1.3 — 宠物状态机 / 在场检测 / 计时与自然语言提醒设计

> 日期：2026-11-03 ｜ 性质：设计规范文档（v0.2.0 状态集 + v0.7.0 实现规范）｜ 前一版：v0.1.2

## 交付

[docs/learning/08-timers-reminders-presence.md](../learning/08-timers-reminders-presence.md)，回答四个问题：

1. **宠物状态集**：10 个状态（idle/happy/sad/thinking/talking/alert/stretch/focus/break/sleep），按来源拆分驱动方（应用系统事件 / Agent 情绪 / AgentEvent 映射 / 在场感知）；优先级链 `alert > focus/break > sleep > mood > idle`，槽位仲裁 + 限时回落 + 迟滞防抖。`thinking`/`talking` 由应用从 AgentEvent 映射，不让模型自己调工具。
2. **在场检测的边界**：OS 只能可靠给出"距上次输入时长"（Windows `GetLastInputInfo` / macOS `CGEventSource`，轮询一个数字、零权限、零内容访问）；**idle = 在场性，≠ 忙碌程度**（读纸质书反例）。用途限定：sleep 状态、离开时推迟提醒弹窗；隐私红线：绝不接键盘事件流、绝不记录输入内容。
3. **计时服务**：时间基准三原则（时间戳/无脑 tick/唤醒补发一次），WebView 节流与系统睡眠不影响正确性；StandupService 与 PomodoroService 完整状态机（含 deferred 分支、10min 弹窗自动收尾、休息不自动续轮）。
4. **自然语言提醒**：四跳责任链（模型解析时间 → 应用硬校验 → reminders 表持久化调度 → 到点通知），上下文注入当前时间、绝对时间 epoch ms 存储、歧义自愈澄清、重启存活、周期提醒明确不支持（引导降级）。
