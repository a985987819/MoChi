# v0.19.1 — 界面精修「和果子点心铺」（补丁）

> 2026-11-18。frontend-design 方法论驱动的样式精修：**不换设计语言**（奶油粉体系与
> v0.13.1 的系统字体决策都保留），把它推向完整——"好甜品店的包装"。

## 设计方向

麻薯本身是点心。精修围绕四个材质关键词执行，全部令牌化、随主题成对：

| 关键词 | 实现 |
|---|---|
| **糖霜** | 用户气泡/发送键/开始专注键从纯色换 135° 糖霜渐变（浅 `#ffa9b7→#ff8fab`，深 `#e88497→#d9546d`），白字对比与原纯色同级 |
| **奶茶影** | 新 `--shadow-ambient`（接触影+环境影双层）与 `--shadow-lift`，卡片/气泡/窗体分层取用；深色翻黑 |
| **纸感** | tiled SVG feTurbulence 噪点（`--grain`）盖在窗口底色上、内容之下（z-index:-1 + isolation），透明度 0.05 |
| **暖光** | `--shell-wash`：窗顶一圈暖光 + 右下角一抹腮红（深色减淡）；标题栏微透让它隐约透上来（color-mix 86%） |

## 设计取舍

1. **不换字体**：v0.13.1 的系统字体决策继续成立（中文字体 5-10MB + 授权）；字体的"性格"
   用**排版处理**补——数字 46px/300/tabular/加字距、阶段标签 uppercase+4px 字距、
   标题 0.02em。克制但可感知。
2. **按压方向是往里**：主按钮 active 用 `translateY(1px) scale(0.97)` 而非弹起——
   软糯点心被按下去的触觉隐喻，与"麻薯"人设一致。
3. **噪点是氛围不是纹理秀**：0.05 透明度、只铺在无底色区域——截图对比看得见"纸"，
   盯着看没有颗粒感。深色下透明度不变（深底上白噪点读起来更轻）。
4. **激活 Tab 用粉不用灰**：原激活态是中性灰底，与"当前在哪"的语义强度不匹配；
   草莓软糖态（淡粉底+粉字）把导航状态拉回主色系。
5. **两处顺手的对比度修复**：`chat-send--stop` / `pomo-btn--stop` 原先继承白字配
   淡粉底（不可读），补 `color: var(--accent-text)`。

## 视觉验证（Edge headless + CDP）

- 深色：暖棕灰底、深糖霜气泡白字可读、助手气泡暗面卡、氛围光减淡——两套一致。
