# v0.29.5 — 素材导出/导入指引上屏

> 用户诉求：导出的素材在换电脑/重装后该怎么导入、在哪里导入，项目里要有明确指示。
> 2026-11-19。

## 目标

- 把「导出 zip → 解压 → 导入」的完整路径写进素材页，而不是只存在于文档里；
- 明确两种回归方式：直接放素材目录（保留原名）或走应用导入（自动规范命名）；
- 说明 zip 不能直接选，避免用户在文件选择器里找不到 zip 时误以为是 bug。

## 功能清单

1. 素材页新增常驻「导入导出的素材」区块：
   - 1 导出：右上角「一键导出当前素材」得到 zip；
   - 2 解压：导入入口只接收图片，zip 必须先解压；
   - 3 导入二选一：
     - **保留原名（推荐）**：「打开目录」→ 把图片放进 `pet-assets/`，放图即生效；
     - **走应用导入**：「选择图片」批量导入 / 每状态「上传」，系统自动规范命名，
       已有同名时序号顺延。
2. 导出成功提示条追加下一步：
   「换电脑时先解压 zip，再把图片放进素材目录（打开目录）或用「选择图片」导入。」
3. `docs/pet-assets.md` 新增 §2.2.1，与页面文案同源。
4. 版本对齐 `0.29.5`。

## 设计取舍

1. **不直接支持导入 zip**：当前导入入口是原生 `<input type="file" accept=图片>`；
   在应用内解压需要引入 zip 解析依赖（或 Rust 命令），为一次迁移操作增加包体与
   安全面不划算。把"先解压"讲清楚，比偷偷接受 zip 更简单可靠。
2. **推荐目录复制而不是一律走导入**：导出的变体文件名（如 `happy_2.png`）直接复制
   会原样保留；走应用导入时，为避免覆盖已有素材，变体序号可能顺延。两种方式都给出，
   由用户按"精确还原 / 省事导入"选择。
3. **指引常驻页面顶部**：迁移是低频但高困惑操作，放在导出按钮同屏比藏进设置/文档
   更容易被看到。
