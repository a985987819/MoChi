## 文件级实现细节

### 配置层

- `src-tauri/tauri.conf.json`：三窗口声明（详见学习文档 §2.2 表格）；`macOSPrivateApi: true`；CSP 白名单（self + img data/blob + connect https，为 v0.3 直连 LLM API 预留）
- `src-tauri/Cargo.toml`：tauri features 加 `tray-icon`；新增 `tauri-plugin-single-instance = "2"`
- `src-tauri/capabilities/default.json`：windows 从模板 `["main"]` 改为三窗口 label；权限仅 `core:default` + `opener:default`（窗口控制权不下放前端）
- `vite.config.ts`：`rollupOptions.input` 三入口 + `@` alias（ESM 下手动推导 `__dirname`）
- `tsconfig.json`：`paths` 别名（TS6 弃用 baseUrl，paths 直接相对解析）

### Rust 层（src-tauri/src/lib.rs，全部重写）

- `run()`：Builder 组装——single-instance 最先注册 → opener → (macOS) Accessory → setup（托盘/事件/定位）→ on_window_event（CloseRequested→hide）→ run
- `setup_tray()`：菜单三项 + `show_menu_on_left_click(false)` + 左键抬起切宠物 + 菜单事件分发（quit 是唯一 `app.exit(0)`）
- `setup_ui_event_listeners()`：`listen_any` 监听 `ui://open-chat` / `ui://hide-chat` / `ui://toggle-pet`；闭包各自 clone AppHandle
- `show_chat()`：show + set_focus（聊天窗需要焦点接输入；宠物窗 show 不夺焦）
- `position_pet_bottom_right()`：物理像素几何计算（monitor.size/outer_size/set_position 全物理像素，margin×scale_factor）
- 事件名常量 `EVT_*` 与前端 `UI_EVENTS` 一一对应，改名需两侧同步

### 前端层

- 三个 HTML 入口 + `src/pages/{pet,chat,alert}/`（main.tsx + App 组件 + css），页面间零 import，只走事件
- `src/shared/events.ts`：`UI_EVENTS` 常量表 + `sendUIEvent()` 封装（教学点：事件协议集中在两份常量里）
- `src/shared/components/MochiPlaceholder.tsx`：内联 SVG 占位形象（v0.2.0 降级为回退链兜底）
- `PetApp`：`data-tauri-drag-region` 全舞台拖动；单击 `requestAnimationFrame` 重播弹跳动画；双击 emit 开聊天；右键暂屏蔽（v0.2 自绘菜单）
- `pet.css`：`html/body background: transparent`（透明窗关键）+ 漂浮/弹跳 keyframes
- ChatApp/AlertApp：骨架占位（ChatApp 的关闭按钮走 `ui://hide-chat` 事件）

### 依赖变化

- npm：React 19 → **18.3**（锁定计划版本）；scripts 新增 `check: tsc --noEmit`
- cargo：+ `tauri-plugin-single-instance`；tauri features + `tray-icon`

## 设计取舍

1. **窗口管理全部收归 Rust**（事件驱动）：权限最小化 + 托盘/双击/未来快捷键共用同一组函数。详见学习文档 §5。
2. **关闭=隐藏、托盘退出**：常驻应用通行生命周期；聊天窗状态免重建。
3. **chat 窗暂用系统标题栏**：压缩 v0.1.0 范围，v0.3.0 做设置 UI 时自绘。
4. **多 HTML 入口**而非单页路由：窗口隔离干净，符合系统直觉。
5. **宠物定位用主屏全高**（非 work area）：任务栏在底部时宠物悬浮其上，v0.1.0 接受，后续版本换 work_area API。

## 踩坑与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| `corepack enable` EPERM | Node 装在 F:\nodeHere，目录无普通用户写权限 | 改 `npm install -g pnpm`（npm prefix 在 F:\NodeJS\node_global，用户级可写），并把该目录加入用户 PATH |
| `tsc` 报 baseUrl deprecated（TS6） | TS 6.0 弃用 baseUrl | 删 baseUrl，`paths` 改为 `"@/*": ["./src/*"]`（无 baseUrl 时相对 tsconfig 解析，但必须带 `./` 前缀） |
| `vite build` 报 `resolve is not defined` | ESM config 无 `__dirname`，且第一版残留 `resolve` 调用 | `import path from "node:path"` + `fileURLToPath(import.meta.url)` 推导 `__dirname` |
| Git Bash 会话找不到 pnpm | 会话启动早于 PATH 更新，且 npm prefix 目录本不在 PATH | 会话内用全路径 `F:/NodeJS/node_global/pnpm`；用户 PATH 已补（新会话生效） |
| `link: extra operand`（链接失败） | Git Bash 自带 coreutils `link.exe` 遮蔽 MSVC `link.exe` | 统一走 `scripts\vsenv.cmd` 包装脚本（见下"构建环境"） |
| `LNK1181 无法打开输入文件 kernel32.lib` | **Windows SDK 未安装**：VS Build Tools 的 VCTools workload 意外没带 SDK；且系统存在"幽灵注册"（MSI 数据库记录已装、文件已失，重装被跳过） | 先 `winget uninstall` 幽灵包，再 `winget install --force` 全新重装 SDK 26100；VS 安装器 `--quiet/--passive` 必须提权启动（`Start-Process -Verb RunAs`），否则 Exit 5007 只登记不安装 |
| tauri 报 "dependency features does not match allowlist" | tauri.conf.json 开了 `macOSPrivateApi`，Cargo 侧未开对应 feature | Cargo.toml：`tauri = { features = ["tray-icon", "macos-private-api"] }` |
| Rust E0618: expected function, found MenuItem | 局部变量 `toggle_pet`（菜单项）**遮蔽**了同名函数 `toggle_pet()` | 变量改名 `toggle_item`；教训：Rust 中值与函数可同名，编译器报错位置不在定义处，读报错要往回看 |

## 构建环境（重要：Windows 本机构建统一走 vsenv）

本机 rustc 不会自动探测 MSVC 环境，且 Git Bash 的 `link.exe` 会遮蔽 MSVC 的。**所有 cargo / tauri 构建命令统一通过包装脚本执行**（自动加载 vcvars64 + cargo PATH）：

```bash
scripts\vsenv.cmd cargo check
scripts\vsenv.cmd pnpm tauri dev
scripts\vsenv.cmd pnpm tauri build
```
