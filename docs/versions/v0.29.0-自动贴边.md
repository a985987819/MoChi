# v0.29.0 — 自动贴边：拖近屏幕边自动躲藏，靠近/提醒时恢复

> 用户诉求："设置中增加自动贴边功能，拖拽松手位置距离屏幕边框很近时自动贴边
> 只留一点点，鼠标经过或有提醒消息时再就近全部显示"。2026-11-19。

## 功能清单

1. 设置页新增「自动贴边」开关（**默认开**，PetSize 分区之后）——开关经
   `state://auto-dock-changed` 同步给 Rust；关闭时立即从躲藏恢复完整显示。
2. 拖拽收尾（吸附后）若窗口边缘离屏幕工作区边 ≤40 逻辑 px 且不是底边 →
   **自动躲藏**：窗口沿该边滑出，只留 16 逻辑 px 一条（底边不躲藏——宠物置顶
   会盖住任务栏，贴边吸附即可）。
3. **唤回**：鼠标进入贴边外侧 48 逻辑 px 唤回带（且沿边落在窗口跨度 ±120
   物理 px 内）→ 就近恢复停靠位（紧贴该边完整显示）；有提醒时
   （show_app_alert）也恢复。
4. 躲藏在重启后不保留（window-state 持久化的躲藏位会被启动可见性校验回退到
   默认位置——躲藏是临时状态）。

## 设计取舍

1. **底边不躲藏**：宠物窗置顶，向底边滑出会盖住任务栏——底边只做贴边吸附
   （v0.10.0 行为）。左右顶三边照常。
2. **躲藏 = 移动窗口而非改尺寸**：宠物形象与窗口大小不变，只是滑出屏幕外留一条
   ——"恢复默认的大小"即恢复完整显示（停靠位紧贴该边）。
3. **躲藏不跨重启**：window-state 插件会把躲藏位持久化，启动可见性校验（v0.9.0
   P0-04）会把它判为不可见并回退默认位——躲藏是临时状态，重启回默认位更符合直觉。
4. **唤醒轮询挂在既有 hit-test 线程**：150ms 轮询已存在（透明区穿透唤回用），
   自动贴边的唤回判定搭同一班轮询，零新增线程。
5. **沿边跨度 ±120 物理 px**：光标必须在该边的窗口附近经过才算（不是整条边）——
   避免宠物躲左下角时用户碰左上角也弹出来。
