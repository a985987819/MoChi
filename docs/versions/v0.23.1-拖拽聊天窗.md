# v0.23.1 — 聊天窗拖拽优化（补丁）

> 用户诉求："希望可以拖拽聊天框，更方便一些"。2026-11-18。

## 目标

标题栏被 6 个 Tab 与关闭钮铺满后，可抓区域只剩标题文字与缝隙——太小。整条标题栏
（含 Tab 两侧空隙）都能抓，另加聊天空态背景可拖。

## 实现细节

| 文件 | 内容 |
|---|---|
| `shared/window-drag.ts`（新） | `dragWindow(e)`：左键按下且不在交互控件（button/input/select/textarea/a/label）上时调 `getCurrentWindow().startDragging()`；失败静默。`isInteractiveTarget` 用 closest 排除 |
| `ChatApp.tsx` | 标题栏移除 `data-tauri-drag-region`（该属性只对携带元素本身生效，Tab 铺满后可抓区太小），改 `onMouseDown={dragWindow}`——Tab 之间的空隙、标题两侧全部可抓 |
| `ChatTab.tsx` | 空态背景 `.chat-empty` 挂同一处理器——第一次见面的引导页也能随手挪窗口（chips 按钮自动排除） |

权限：`core:window:allow-start-dragging` 属 core:window:default（core:default 一部分），
无需改 capability。

## 设计取舍

1. **手动 handler 替代 drag-region 属性**：属性按 event.target 精确匹配，子元素会
   挡住父级；手动方案可以声明排除规则，交互控件之外整块可抓。
2. **空态背景可拖**：空态页只有一句话 + 4 枚 chips，大面积留白正是最好的抓手；
   chips 经 closest 排除，点击行为不变。消息列表**不**加入——列表要滚动和选文本，
   抓取会打架。
3. **失败静默**：startDragging 权限异常时拖不动但不报错——窗口移动不该变成一次报错。
