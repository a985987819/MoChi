# P0-01 拖拽惯性与落地手感

- **状态**：claimed: workbuddy-claude（2026-11-17）
- **优先级**：P0（手感）
- **依赖**：无
- **涉及文件**：`src-tauri/src/lib.rs`（`DragMotion` / `start_native_tick` / `snap_to_work_area`）、
  `src/pages/pet/PetApp.tsx`（仅 `gripping` 视觉反馈，可能不需要改）

## 背景

拖拽走的是 OS 原生 `start_dragging()`（`ui://drag-pet` → `pet.start_dragging()`），
松手即停、零惯性。桌宠的"手感"很大程度来自"被扔出去会滑一下、撞到边会停住"。
v0.10.0 已补了松手后的**贴边吸附**（`snap_pet_to_edges`），惯性是同一层能力的另一半。

## 目标

- 快速甩动后松手，窗口按最后速度继续滑行，摩擦衰减到停止；
- 滑到工作区边缘**停住**（不是反弹；主人把它放边上通常就是想让它在边上）；
- 全程 ≤600ms、总位移有上限，别出现"飞出去半屏"的失控感；
- 用户一旦再次按下（新的 `Moved` / `drag-pet`），惯性立即终止。

## 非目标

- 不做"落地弹跳/压扁"这类形变动画（需要素材配合，另立项）；
- 不做抛掷音效（音效在 P0-02）。

## 设计建议（可推翻，但请写下理由）

1. **采样**：`DragMotion` 目前只有 `dragging` + `last_move_at`。加一个固定长度环形缓冲
   （建议 6 个样本，存 `(x, y, Instant)`），在 `WindowEvent::Moved` 里 push。
   只保留最近 ~120ms 的样本，避免把整段拖拽平均成"很慢"。
2. **速度**：`v = (last.pos - first.pos) / (last.ts - first.ts)`，单位 px/ms，转 px/s。
   样本不足 2 个或时间差 <16ms → 不给惯性（避免抖动被当成甩动）。
3. **积分**：主线程定时器（建议 16ms）逐步 `set_position`，`v *= 0.88` 每帧，
   `|v| < 40px/s` 或已运行 600ms 或单次位移超 400px 时停止。
4. **边界**：每帧把目标位置 clamp 到**当前显示器工作区**（`snap_to_work_area` 的思路可复用，
   但这里要允许"已经在外面"的情况：先 clamp 再判停，撞边即 `v = 0`）。
5. **收尾**：惯性结束后**再**调一次 `snap_pet_to_edges`，让最终位置仍然对齐边。
6. **取消**：新的 `Moved`（用户又按住了）或 `drag-pet` 事件 → 立刻停表。

## 接口与测试

把物理算成纯函数，单元测试就能覆盖边界（这是这类功能唯一可靠的验证手段）：

```rust
/// 返回 (新位置, 新速度, 是否结束)
fn inertia_step(
    pos: (i32, i32), vel: (f64, f64), dt_ms: f64,
    size: (u32, u32), area: (i32, i32, u32, u32),
) -> ((i32, i32), (f64, f64), bool)
```

单测至少覆盖：撞左边归零、撞右边归零、慢速立即结束、单帧位移过大被截断、
面积为零时不动（防御）。

## 验收标准

- [ ] `inertia_step` 单测 ≥5 例全绿；`cargo test` 保持全绿。
- [ ] `pnpm check` / `pnpm test` 不受影响（本任务应只动 Rust）。
- [ ] 真机：轻拖（慢放）不滑；快速甩动滑行 ≤半屏；撞边停住不再穿出屏幕；
      拖拽中再次按住立即停止（**需用户本人确认手感**）。
- [ ] 版本文档记录"为什么选摩擦模型而不是弹簧模型"。

## 坑

- **别在持锁时调窗口 API**：`Mutex<DragMotion>` 的 guard 必须在调用 `set_position` 前释放
  （v0.10.0 已踩过，见 `docs/versions/v0.10.0-活起来与礼貌.md` 踩坑 ③）。
- **window-state 插件会持续记录位置**：惯性期间位置不断变化，退出时保存的是最终位置，
  这是期望行为；但要确认不会与"贴边吸附"抢最后一步。
- **多屏与负坐标**：`current_monitor()` 在拖动跨屏瞬间可能返回旧屏，导致边缘判定错一帧——
  允许，但别让它把窗口甩到屏幕外。
- **游戏模式**正在隐藏宠物时不要跑惯性（`hidden_by_gm` 为真就直接返回）。
