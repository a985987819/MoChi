## 文件级实现细节

- `scripts/gen-icon.mjs`：手写 PNG 编码器（IHDR/IDAT/IEND + CRC32 + zlib）+ 距离场绘制（椭圆体/贝塞尔嘴线/2.5px 抗锯齿边）——一次性产物的零依赖方案，`node scripts/gen-icon.mjs` 复现
- `tauri.conf.json` bundle 段：nsis.languages SimpChinese/English + installMode currentUser（数据仍在 appData 不受影响）
- `release.yml`：macOS `--target universal-apple-darwin`（dtolnay toolchain targets 双架构）；releaseDraft: true——CI 只产 draft，**正式发布 = 所有者在 GitHub 上确认**，与 AGENTS.md 部署纪律对齐
- 首次构建自动下载 NSIS 3.13 / WiX 3.14 工具链（tauri CLI 托管）

## 设计取舍

1. **手写 PNG 生成器而非引 canvas/sharp**：一次性图标产物不值得引入绘制依赖；脚本即文档。
2. **NSIS 为主、MSI 为辅**：NSIS 支持简体中文与 per-user 安装（现代推荐路径）；MSI 保留企业场景，语言保持 en-US（WiX zh-CN 需额外语言包，降低首建可靠性）。
3. **CI Release 走 draft**：把"对外发布"这个不可逆动作留给人工确认——工作流自动化到 draft 为止（07 §5 确认回环思想在发布流程的应用）。
4. **macOS 未签名**：个人分发可接受（右键→打开绕过 Gatekeeper），签名公证是 v2 事项（需 Apple Developer 账号）。

## 踩坑与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| Uint8ClampedArray 无 `.copy` | PNG 编码器误用 Buffer API | 改 `raw.set(subarray(...))` |
| NSIS/WiX 工具链缺失 | 首次打包 | tauri CLI 自动下载（构建日志可见） |
