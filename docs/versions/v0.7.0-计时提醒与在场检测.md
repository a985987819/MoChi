## 文件级实现细节

### Rust（src-tauri/src/lib.rs）

- `get_idle_seconds`：`user_idle::UserIdle::get_time()`（0.2.1 的真实 API——`Idle` 是我猜错的，读 registry 源码修正）；失败返回 0（按在场处理）。
- `show_alert`：从宠物 outer_position/outer_size 计算弹窗位置（正上方 12px），物理像素。
- `ui://show-alert` / `ui://standup-ack` 监听：show / hide。

### 服务（src/services/）

- `timers.ts`：两服务的时间基准三原则落地（tick 只做比较与广播）；StandupService 状态 armed|fired（deferred 语义合并进 armed：away 时 deadline 已过但不 fire，恢复即弹）；PomodoroService 阶段迁移幂等。
- `presence.ts`：轮询 → 迟滞 → petState presence 槽 + 广播。
- `reminders.ts`：Store/Scheduler 双组件分驻两窗口，**单一事实源 = SQLite**；认领 SQL `UPDATE ... WHERE status='active'` rowsAffected===1。
- `notifications.ts`：权限检查 + 发送统一入口。
- `settings.ts`：+4 字段（standupIntervalMin/pomodoroFocusMin/pomodoroBreakMin/notificationsEnabled，clampInt 夹紧）+ 保存即广播 settingsChanged。

### 内核与工具

- `pet-state.ts`：+clearPresence（PresenceService 恢复时调用）。
- `context-builder.ts`：+now 参数与 formatCurrentTime（Intl weekday + UTC 偏移）。
- `tools/pomodoro.ts`：PomodoroControl 注入（start/stop 遥控 + cachedStatus 读 chat 窗广播缓存——Tab 打开时必然新鲜）；"已在专注中"返回 ok:false 供模型澄清。
- `tools/reminder.ts`：parseFireAt 独立可测函数；create_reminder description 含"绝对时间解析指引 + 周期提醒降级话术 + 与 add_todo 的边界"。
- `facade.ts`：+reminderStore/pomodoro 控制 + 6 工具注册 + buildMessages 传 now；pomodoroChanged 缓存监听。

## 设计取舍

1. **提醒调度驻留宠物窗 + DB 轮询**（而非 chat 窗服务）：宠物窗是生命周期最长的宿主；DB 是唯一事实源，认领 SQL 保证幂等——比跨窗口状态同步简单可靠（08 §5.4）。
2. **StandupService 砍掉 deferred 显式状态**：away 时不 fire 即隐式推迟（deadline 已过去，恢复后首个 tick 立即触发）——状态机少一态，语义不变。
3. **get_pomodoro_status 读广播缓存**：chat 窗打开时每秒新鲜；避免跨窗口请求-响应的复杂度。注释已声明新鲜度边界。
4. **番茄钟配置热更新不影响进行中的轮次**：时间基准已在跑，下一轮生效（tick 注释）。
5. **通知开关统一三服务**：一处开关管全部打扰面（用户心智简单）。

## 踩坑与解决

| 问题 | 原因 | 解决 |
|---|---|---|
| `could not find Idle in user_idle` | API 猜测错误（0.2.1 的结构体叫 UserIdle） | 读 `~/.cargo/registry/src` 的 crate 源码确认（grep pub struct/fn）——**离线查证依赖 API 的标准姿势** |
| facade listen 参数隐式 any | 误从 "@/shared/events" 导入 listen（不存在）→ any 感染 | 改从 @tauri-apps/api/event 导入 |
| PomodoroStatus 跨窗口类型不匹配 | 广播载荷用 string 弱化 vs 侧 union 类型 | 工具层定义 PomodoroStatusLite 宽松形状（跨窗口载荷不做类型强约束） |
| presence/reminders/pomodoro 未用导入等 6 处 | 批量编写 | 逐一清理 |
