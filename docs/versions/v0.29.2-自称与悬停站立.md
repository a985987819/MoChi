# v0.29.2 — 自称全站生效 + 悬停站立时长

> 用户诉求：① 修改宠物自称后，界面应全部使用新自称（例如自称「熊」时首页显示
> 「跟熊说句话吧～」），弹窗与设置里的名字也一样；② 取消「单击宠物重置站立」，
> 改为鼠标悬停时在头顶显示「上次站立是 xx 分钟前」。2026-11-19。

## 目标

- 自称只有一个事实源（settings.petSelfName），UI 不再散落硬编码的「麻薯 / Mochi」。
- 站立计时与单击手势解耦：点击只保留"摸摸头"反馈，不再暗中重置久坐计时。
- 悬停即可看到上次站立时长，替代原来不直观的"单击清零"。

## 功能清单

1. **`{pet}` 自动插值**：i18n 内核新增当前自称状态，`t()` 自动把文案里的 `{pet}`
   替换为 settings.petSelfName；`installLocaleWatcher` 在 settingsChanged 时同步，
   `useT` 以 revision 为快照，改名后所有 React 文案即时重渲染。
2. **全站改名覆盖**：
   - 首页空态「跟{pet}说句话吧～」、新手引导「你好，我是{pet}」；
   - 待办 / 番茄钟 / 提醒中心的空态提示；
   - 设置页：开机自启、TTS、游戏模式、宠物大小、称呼说明等标签与注释；
   - 右键菜单「隐藏{pet}」、版本更新标语、占位形象 aria；
   - 登录自启等系统级说明保持产品名 Mochi（不把安装包/应用标识改成自称）。
3. **弹窗与通知**：站立提醒的弹窗标题/正文、系统通知正文、番茄钟完成/休息结束的
   弹窗与通知改为 i18n 文案，正文里的名字走 `{pet}`。
4. **取消单击重置站立**：
   - 宠物单击只弹跳 + 暖心气泡，不再发 `resetStandup`；
   - 新增 `ui://pet-clicked` 专用于"打断朗读"，聊天窗监听后停止 TTS；
   - 站立计时只由提醒弹窗确认或右键菜单「站立提醒 · 还剩 N 分钟」主动重置。
5. **悬停显示上次站立时长**：
   - `StandupService` 记录 `lastStandupAt`（确认提醒 / 主动重置时更新，改配置不更新）；
   - 指针在形象矩形内时头顶显示「上次站立是 {minutes} 分钟前」，每 30 秒刷新；
   - 菜单打开、拖动、窗口失焦、气泡显示时自动让位。
6. **周边一致性**：托盘菜单改为中性的「显示 / 隐藏宠物」；安装器《快速上手》同步
   移除单击重置说明、更新右键菜单项与悬停提示。
7. 版本对齐 `0.29.2`。

## 设计取舍

1. **在 `t()` 里自动注入 `{pet}`，而不是给每个调用点加参数**：文案入口只有一个，
   漏传名字的 bug 面从"几十处"收敛到"字典里有没有写 `{pet}`"；同时保留显式
   `vars.pet` 覆盖能力，测试与特殊场景可控制。
2. **revision 快照而非 locale 快照**：`useSyncExternalStore` 只在快照变化时重渲染。
   语言不变、自称变化时 locale 字符串不变，必须用单调递增的 revision 才能触发。
3. **悬停复用点击穿透的命中检测**：宠物窗透明区很大，已有 pointermove → 形象矩形
   判定；悬停状态搭同一趟车，无需新增监听器。菜单/拖动/失焦统一收起，避免残留。
4. **"上次站立"只存在内存**：站立计时本身重启即归零，"上次站立"跟着服务生命周期
   走语义一致；持久化反而会和重启后的计时状态打架。
5. **单击保留气泡、去掉计时副作用**：点击仍是"摸摸头"的情感反馈；需要打断 TTS 的
   场景改用 `petClicked` 事件，避免为了停朗读而误重置久坐计时。
6. **托盘/安装器用中性词**：原生托盘菜单在 Rust 启动时构建，动态改文案需要额外的
   跨进程状态同步；产品级入口用「宠物」比显示一个可能过期的自称更稳。应用内外观
   文案（弹窗、设置、空态、菜单项）全部跟随自称。

## 踩坑与解决

1. **`t()` 自动替换会改变"未知占位保留"测试的语义**：只注入 `pet`，`{minutes}` 等
   未传变量仍原样保留，既有测试继续通过；新增自称注入用例覆盖。
2. **中文/英文占位符必须成对**：新增的 `pomodoro.notifyBody`、`pomodoro.awayNote`、
   `standup.notifyBody` 等 key 在两侧保持相同占位集合，`i18n.test` 的占位对齐断言
   继续生效。
3. **服务层文案读不到最新自称的时序**：`timers.ts` 用 `t()`，依赖各窗口启动时调用
   `installLocaleWatcher`；宠物窗是服务宿主，watcher 在服务启动前安装，提醒触发时
   自称已同步。
4. **悬停小字与暖心气泡抢位置**：两者都在头顶；渲染条件加 `!bubble`，点击冒气泡时
   自动让位，气泡消失后若仍悬停会重新出现。
5. **窗口穿透导致 hover 卡住**：指针离开形象时同一次 pointermove 先把 hover 置
   false 再设置 click-through，不会留下悬空提示。
6. **托盘菜单是原生静态文案**：本次改为中性「显示 / 隐藏宠物」，避免改名后托盘仍
   显示「麻薯」；产品名 Mochi 的安装/退出等标识不变。
