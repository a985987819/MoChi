# 单击麻薯的小纸条

确认一次单击后，麻薯轻轻弹跳，头顶弹出一张奶油白气泡。约 7 秒阅读、200ms 淡出；再点换一条，双击/拖动/右键菜单/失焦或隐藏时收起。气泡不拦截鼠标，不替代到点提醒弹窗。

单击仍按原约定重置站立计时；这只代表点击，不代表已起身。双击打开聊天、拖动移动宠物均不会被当成单击。

## 文案与语境

内置 **144 条、12 类，每类 12 条**。默认称呼为「麻薯」「人」，复用设置页的两个称呼输入框。

| 类别 | 何时优先选用 | 例子 |
|---|---|---|
| 早安 | 本地 05:00–10:59 | 早安。脑袋可以慢慢开机，不着急。 |
| 午间 | 11:00–13:59 | 中午啦，肚子有没有发来开饭申请？ |
| 下午 | 14:00–17:59 | 如果困了，先歇歇，不和眼皮拔河。 |
| 晚间 | 18:00–21:59 | 晚饭吃了吗？肚子的消息也值得回复。 |
| 夜深 | 22:00–04:59 | 枕头可能想你了，要去见见它吗？ |
| 专注 | 番茄钟 focus | 专注计时还在走，我把加油调成静音。 |
| 休息 | 番茄钟 break | 小脚丫申请出场，起来走两步好吗？ |
| 小休息建议 | 当前活动段约 45 分钟以上 | 让肩膀下班一分钟，回来再慢慢来。 |
| 欢迎回来 | 恢复输入后短时间内 | 欢迎回来，人。你的小桌宠在这。 |
| 摸摸玩笑 | 连续摸摸/随机穿插 | 再摸一下，麻薯就要变成糯米糍了。 |
| 轻声陪伴 | sad 状态/随机穿插 | 这里不用表现得很厉害，待着就好。 |
| 日常 | 随机穿插 | 水杯在等一个举高高，要理理它吗？ |

只在你点麻薯时出现，不会为了早晚问候主动打断工作。优先回应新时段/专注阶段，之后穿插日常、陪伴和玩笑；近 12 条记录用于避重，尽量不连说同类。15 秒内连续确认三次单击可触发俏皮回应；双击不会增加摸摸次数。

## “忙不忙”从哪里来

番茄钟的 focus/break 是明确的应用状态。普通活动段只依据已有“距上次输入多久”的聚合信号，离开后/长时间无观测后重新计算，不读取键盘内容、前台程序、工作文件或浏览记录；不能知道你是否真在忙、是否一直坐着或是否看着屏幕。

因此活动段较长只用于选“要不要休息一下”的邀请，不会报出“你已经工作/坐了多少分钟”。站立计时与活动段分开，摸摸重置站立计时不会把文案的活动记录也清零。记录仅在当前进程内，重启归零。

## 怎么扩展文案

源文件：[pet-chatter-lines.ts](../src/services/pet-chatter-lines.ts)。在对应分组末尾追加短句：

```ts
"{user}，喝水和发呆都可以插个队。"
"{pet}的隐藏技能：陪你无所事事。"
```

`{user}` 替换「ta对我的称呼」，`{pet}` 替换「ta自称」。气泡空间小，长称呼只在气泡中缩为前七个 Unicode 字符加省略号，不改变设置或聊天使用的完整称呼。新增句子保持唯一、短小、不捏造用户行为；同组只往末尾追加，避免已有编号改变。

选择逻辑位于 `services/pet-chatter.ts`，上下文适配位于 `pet-chatter-context.ts`；UI 位于 `pages/pet/PetBubble.tsx`。无需模型、Key 或网络，也不产生模型调用费用。动态效果遵循系统“减少动态效果”偏好。

## 验证

`pnpm test` 覆盖时段边界、阶段切换、去重/回来/连点、称呼、活动段、异步取消、显示与退场；`scripts/ui-smoke.cjs` 用真实浏览器+Tauri官方IPC mocks检查实际窗口尺寸、文字不裁切、切换专注、自动消失和原有手势/提醒回归。浏览器通过不等于原生桌面验收，原生窗口效果仍按 roadmap 记录。
