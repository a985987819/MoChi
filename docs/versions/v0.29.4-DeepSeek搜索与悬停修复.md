# v0.29.4 — 联网搜索接入 DeepSeek + 悬停提示失焦/延迟隐藏

> 用户诉求：① 按方案 1 把 `web_search` 接入 DeepSeek Search API，并增加对应标示与
> 说明；② 修复桌宠 hover 提示在失焦时不消失的问题，改为鼠标进入即出现、离开 5 秒
> 后隐藏。2026-11-19。

## 目标

- 有 DeepSeek Key 时使用 DeepSeek 自研搜索，结果更贴近中文/时事查询；
- 没有 Key 或请求失败时自动回退维基百科，保持"开箱可用"；
- 设置页明确展示当前数据源、计费方式与 Key 复用关系；
- 悬停提示有明确的进入/离开/失焦生命周期，不再永久悬空。

## 功能清单

1. **`web_search` 双数据源**：
   - 读取 `settings.apiKeys.deepseek`；
   - 有 Key → `POST https://api.deepseek.com/v1/tools/search`
     （`count` 1~5、`need_content: false`，Bearer 鉴权）；
   - `summary`（约 600~800 字）映射为 `snippet`，`title/url` 原样；
   - 无 Key、请求失败或零结果 → 维基百科 MediaWiki API（`origin=*`）兜底；
   - `data.source` 标明 `DeepSeek Search API` / 维基站点，便于调试与说明；
   - 失败仍返回 `ok:true + note`，不炸 Agent 循环。
2. **设置页「联网搜索」说明**：
   - 显示当前数据源（检测到 DeepSeek Key → DeepSeek Search API；否则维基百科）；
   - 说明计费：约 5 元 / 1000 次成功搜索，失败/零结果不计费；
   - 说明自动回退维基百科，以及"复用 DeepSeek 提供商下的 Key，无需单独配置"。
3. **悬停提示生命周期**：
   - 鼠标进入形象：立即显示「上次站立是 N 分钟前」；
   - 鼠标离开形象/窗口：启动 5 秒延迟隐藏，期间重新进入会取消；
   - 窗口失焦（`window.blur` / Tauri `onFocusChanged(false)` / 页面隐藏）：
     立即隐藏，修复"失焦后提示不消失"；
   - 打开右键菜单、开始拖动：立即隐藏；
   - 组件卸载清理延迟定时器。
4. 版本对齐 `0.29.4`。

## 设计取舍

1. **用 Search API 而不是服务端 `deepseek_web_search` 工具**：
   - Search API 是普通 JSON 接口，`web_search` 的输入/输出形状不变，Agent 循环、
     工具轨迹、现有测试全部复用；
   - 服务端工具需要扩展 Provider 的流式协议（`server_tool_use`、
     `web_search_tool_result`、`citations`），且文档要求使用 `deepseek-flash`，
     对现有 `deepseek-chat` 用户与多提供商架构侵入较大。
2. **Search API 按次计费**：约 5 元 / 1000 次成功搜索；比服务端工具"只算 token"
   更贵，但实现简单、模型无关。设置页明确标注价格，避免用户不知情。
3. **不新增独立搜索 Key**：直接复用 DeepSeek 提供商下的 Key，少一个配置项；
   没有 Key 的用户继续用维基百科。
4. **失败/零结果走维基兜底**：DeepSeek 402/429/网络错误不应该让搜索能力整体失效；
   兜底保证基础体验。
5. **离开 5 秒后隐藏而不是立即**：给"鼠标短暂划过"留阅读时间；失焦则立即隐藏，
   两者语义不同，分别用延迟定时器和 `hideHoverNow`。
6. **Tauri `onFocusChanged` 兜底**：宠物窗 `focus: false`，某些场景下 `window.blur`
   不触发；窗口级焦点事件更可靠，失败时静默降级。

## 踩坑与解决

1. **DeepSeek API 的 CORS**：与现有 Provider 一样从 WebView `fetch`；若被浏览器
   拦截，会自动落到维基百科，不影响可用性。后续若要强依赖，可换 `tauri-plugin-http`。
2. **`summary` 与 `snippet` 取舍**：`need_content:false` 时 `content` 为空；
   用 `summary` 作 `snippet` 才能给模型足够上下文，同时避免整页正文撑爆预算。
3. **Key 安全**：错误文案只保留 HTTP 状态码；Authorization 只出现在请求头，
   不写日志、不回传给模型。
4. **延迟隐藏定时器泄漏**：组件卸载、立即隐藏、重新进入三条路径都调用
   `clearHoverHide`，避免旧定时器把新一次悬停关掉。
5. **穿透导致 pointerleave 不触发**：离开形象时 `updateHitTest` 已启动 5 秒定时器；
   `pointerleave` 是窗口级补充，两者幂等。
